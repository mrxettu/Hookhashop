# Hookhashop frontend scaffold

This repository was initialized with a React + Vite + Tailwind scaffold.

What I added:
- Vite + React app files
- Tailwind CSS config and PostCSS
- Basic routes: /, /shop, /product/:id
- Components: Header, Footer, ProductCard
- Sample products JSON (src/data/products.json) referencing the original store image URLs (hotlink). 

How to run locally:
1. npm install
2. npm run dev

About images:
- You previously requested I download the original site's images into the repo. In this environment I cannot fetch and store external images automatically.
- Currently the example products hotlink images from worldhookahmarket.com so the UI shows real product images. To embed images into the repository, please either:
  - upload a ZIP of the images here and I will add them to src/assets/images and update product entries, or
  - provide a list of direct image URLs and I will attempt to import them if allowed.
